## The Last of the TMNT - A Rom hack by KungFusedMike (KFM)

Play as the Last of the TMNT. You have access to all sub weapons from the start of the game and one turtle to survive.

## The following modifications have been made:
- Only 1 turtle. Select your turtle with the "Select" button during attract mode/title screen.
- You start with 20 of each sub weapon. Press "start" while in sub areas to switch sub weapons on the fly
- No continues
- No turtle rescues
- No static or random weapon drops
- You have increased health
